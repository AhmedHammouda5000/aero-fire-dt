2PROPOSITION DE VALEUR

Un copilote qui lit le SSI sans jamais pouvoir le toucher.

  • Lecture seule, isolée, posée par l'installateur agréé ; aucun remplacement du SSI
  • « FEU » seulement si 2 signes physiques sont d'accord (double boucle aéronautique)
  • Verdict < 60 s dans la levée de doute ; pendant une alarme SSI : « appliquer la procédure », jamais de score
  • Alerte précoce « feu couvant possible » ; prévision de fumée à 60 s
  • Apprend chaque site pendant 90 jours
  • Hors ligne, sur batterie (≈ 55 h) pendant les coupures STEG
  • Prototype : 17/17 feux, 11/15 nuisances rejetées (essais réels jamais vus) ; gain réel mesuré au pilote
